Work lost to a crash is offered back. When the same model is opened again after a session that did not close (no page unload), and its autosave holds something the last project file saved or opened does not, that autosave is kept aside and the intro screen and the project drawer show its time and model name with Restore and Discard. It stays on offer, across sessions too, until Discard is pressed. Restore is a swap: the project in front is kept in the slot and offered in its place, so work done after the crash is not lost and restoring again brings it back; a session that closed normally is put back as before. Project files now carry a version, older files are brought up to date by migrations on open, and a file from a newer IfcSheet is refused with a message instead of being half-loaded. A project package records its project file version, so an older package is migrated the same way. An autosave written by a newer IfcSheet is left as it is: it is not loaded, this version does not autosave over it, and a notice says so. An autosave the browser refuses to store (a full quota) is shown as a notice, not only logged.
