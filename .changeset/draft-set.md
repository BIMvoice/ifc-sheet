**Draft set.** The **Draft set** button beside New sheet in the Project Navigator, or the `DRAFTSET` command, makes the same drawing set the Wall starts with, from the model: a plan per storey, the four elevations and the first proposed sections (marked on the ground-floor plan), each placed on a sheet. Plans go on A-1xx sheets, elevations on A-2xx, sections on A-3xx. Sections and elevations get a view depth that reaches the far side of the building. Everything is an ordinary view or sheet to correct afterwards. One Undo removes the whole set, and running it again adds only what is missing.
