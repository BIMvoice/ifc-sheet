The whole set of sheets can be issued in one action: type `ISSUE` (optionally `ISSUE SVG` or `ISSUE DXF`, then a name) or use the new Issue the set section of the sheet panel. You get one PDF with every sheet on a page of its own paper size and orientation, in sheet-number order, with the drawing list as an optional first page; a drawing list as CSV; or a zip with one SVG or DXF per sheet. Sheets with nothing on them are left out and the report says so. Each issue is recorded with the project (name, date, and each sheet with its title, scale, paper, revision and a content fingerprint) so a later issue can say what changed.
