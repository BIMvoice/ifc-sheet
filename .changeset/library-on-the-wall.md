The Wall can carry an office's library file (`.bvlib`) between projects. "Import library" and "Export library" sit in the project drawer under New, Open and Save. Export lets you choose which kinds go into `<project name>.bvlib`. Import shows what is in the file, lets you choose the rule for names the project already has (keep mine, take theirs, keep both; keep mine to start with), and shows the counts per kind before and after you press Import. A broken file, or one made by a newer version, is refused with the reader's message and changes nothing. The rail's tag, level, dimension, note and hatch tools now offer the project's annotation types, and the symbol tool its symbols, so what an imported library brings is one choice away.
