Three drawing-set tools: `ifcsheet_open_model` opens an IFC file (path or base64) and returns a model handle with a summary, `ifcsheet_generate_set` lays out its default set of sheets, and `ifcsheet_export_pdf` writes the set as a PDF to a path or returns it as base64. First slice of the drawing-set tools.
