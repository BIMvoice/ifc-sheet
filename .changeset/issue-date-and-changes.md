Issuing the set now lets you choose the issue date (it starts as today) and lists what changed since the last issue before you issue. The date is printed as the date in each sheet's title block, on the drawing list and in the handover file names, and is kept with the issue record. The panel lists the sheets added, removed and changed since the previous issue; a sheet counts as changed when what the project holds for it changed (its settings, the views and drawn annotations on it, its revisions). Changes to the model itself are still listed by What changed. When the previous issue has no content fingerprints, the panel says changes can't be listed instead of saying nothing changed. Changed sheets whose revision was not raised get an "Add a revision to these N sheets" button (one undo step). The list is kept in the issue record and becomes a Change column in the drawing list (CSV, PDF page and handover register). New in English and Romanian.
