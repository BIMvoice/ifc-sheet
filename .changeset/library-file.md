A library file (`.bvlib`) carries a project's reusable definitions — layers and layer groups, text and dimension styles, hatch patterns, materials with their drawing settings, annotation types, symbols and legend configurations — from one project to another. The Drafting standards dialog gains a Library tab to export a chosen selection and to import a file under a rule for name clashes (keep mine, take theirs, or keep both, with references between definitions carried along), and an Annotation types tab: a type presets an annotation tool (text or dimension style, layer, and the options of axes, hatches and tags) and "Draw with it" starts the tool with those settings. Projects saved before this open unchanged.
