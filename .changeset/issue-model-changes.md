The list of what changed since the last issue now includes the sheets a change in the model reaches. An issue records a reference to the model as it went out (a fingerprint, the size and the time; the state itself rides with the project's model state, for the last issue only, and not at all when it is the reference), and the next issue compares the model now with it by What changed's own comparison. Each changed sheet says why: edited, model changed, or both. An issue made before the model was recorded says that model changes since it can't be listed.
